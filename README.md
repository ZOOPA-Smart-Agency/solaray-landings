# Solaray · Landings de pack

Maquetas de las landings de la campaña «Vuelve a tu ritmo» para revisión con cliente. Web oculta a buscadores.

- Pack Energía y Foco: `landing-pack-energia-y-foco.html`
- Guía de estilo: `guia-estilo.html`

## Estados fijos (para exportar a Figma con html.to.design)

Añadir parámetros a la dirección de la landing:

- `?figma=1` — todo visible y sin animaciones (usar siempre al exportar)
- `&panel=1..6` — abre ese panel de «Qué hace»
- `&sol=manana|mediodia|tarde|noche` — fija el gráfico del sol
- `&compra=custom` — abre «Elige tus productos»
- `&vitc=30|100` — formato de la vitamina C
